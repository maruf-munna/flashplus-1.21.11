## A VFX Pipeline tool for Minecraft

Exactly what it says on the tin.

Current features
- Entity Tracking
- Camera Path Exporting
- Panorama Export (for HDRIs)

Planned but not implemented yet:
- Depth Map exporting
- World Exporting

To import into Blender you will need an addon:
https://github.com/FalseMSP/RedsFlashbackImporter

Modrinth: https://modrinth.com/mod/flashplus
Showcase: https://www.youtube.com/watch?v=NePRDbeOILg
